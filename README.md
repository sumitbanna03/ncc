This is a cricket club website for Nihalwadi cricket club from Nihalwadi(my hometown).I built this platform from scratch to help manage and celebrate my village's local cricket club. It handles everything from player profiles and match statistics to tournament memories.
The Tech Behind It:
 🔹 Backend: Node.js & Express.js
 🔹 Database: MongoDB & Mongoose
 🔹 Frontend: HTML, CSS, JavaScript, and EJS templates
